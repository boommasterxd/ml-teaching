# HSTS on Vercel Bot Protection responses

The maintainer accepts PRIV-01 for HTTPS responses generated by Vercel Bot
Protection before the request reaches ML Teaching. These challenge responses
can return HTTP 429 without a `Strict-Transport-Security` header. A browser
without a stored HSTS policy cannot establish one from that response alone.

The challenge is owned by Vercel. The application continues to send the full
HSTS policy on its own HTTPS responses through `next.config.mjs`. The acceptance
applies only to the provider challenge while application responses retain that
policy.
