# Public repository visibility

The maintainer accepts public exposure of the existing Git history and retained
GitHub Actions logs with the following known conditions.

- Personal email addresses in historical commit metadata and an older version
  of the security policy may become publicly searchable.
- Historical revisions contain the former Ada Lovelace Project logo. Permission
  to redistribute that logo in the public repository remains unverified.
- The retained Actions logs have partial review coverage for confidential
  content. Any confidential content in the remaining logs would become visible.

[GitHub documents the effects of changing repository visibility](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility).

The public repository uses GitHub's `collaborators_only` policy for opening pull
requests. The repository owner and invited collaborators can open pull requests.
