# Visual accessibility in learning exercises

- **ACCESS-01, accepted.** The maintainer considers a text representation of the
  changing spatial relationships in the live feature plot impractical for this
  learning exercise. The plot positions remain visual. The predicted class and
  confidence values are available as text.
- **ACCESS-02, accepted.** The maintainer accepts numbered training examples
  without image descriptions because learners supply or capture their own
  images. The gallery and preview support keyboard use. Screen-reader users
  can identify an example by its number but cannot inspect its visual content.
- **ACCESS-03, accepted.** The maintainer prefers feedback at the selected point
  in the KNN exercise. On narrow screens, the Tooltip can cover another data point.
  The first tap on that point may dismiss the Tooltip, after which the learner can
  tap the point again. Escape also dismisses the Tooltip.

The public accessibility statement describes these limitations.
